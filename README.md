# Antigravity Mobile Remote (Android APK)

Беспроводной мобильный клиент для удалённого управления сессиями Google Antigravity:
- Группировка диалогов по проектам (как в Antigravity).
- Работает по домашней локальной сети Wi-Fi.
- Не требует авторизации Google на телефоне.
- Голосовой ввод и быстрые действия (Proceed, Статус, Продолжай).
